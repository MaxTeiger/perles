# Perles

Jeu de tri de perles en pixel art (HTML + JS, sans dépendance), publié sur https://perles.maxteiger.com via GitHub Pages.

Touche un lot : ses perles rejoignent les plateaux. Un plateau de 9 perles d'une même couleur se pose sur l'image. Bloqué ? Un plateau bonus par partie. Le bouton « Ta photo » transforme n'importe quelle image en niveau (24×24, 7 couleurs, rien n'est envoyé : tout se fait dans le navigateur).

Nombre de plateaux = nombre de couleurs (4 à 7), réglé par simulation pour qu'un bot simple gagne environ 2 parties sur 3.
